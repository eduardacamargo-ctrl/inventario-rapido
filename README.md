# Inventário rápido

Aplicativo estático para registrar código de barras, quantidade e horário usando celular.

## Publicação no Render

1. Envie estes arquivos para um repositório GitHub.
2. No Render, crie um Blueprint e selecione o repositório.
3. O Render lê `render.yaml` e publica automaticamente o site.

O endereço público terá HTTPS, necessário para a câmera do celular.
